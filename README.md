# Amrkmn Tap

## How do I install these formulae?

`brew install amrkmn/tap/<formula>`

Or `brew tap amrkmn/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "amrkmn/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
